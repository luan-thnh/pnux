The new pnux9 npm package is ready for the maintainer to publish (subject to npm name approval). Until then, clone the GitHub source and run npm start or npm link.

Designed to stay out of your system's way.

PNUX only shows processes it can safely offer to stop under the current user. It never requires root privileges and never silently kills anything.

Before a stop, PNUX checks process and socket identity again, and sends a graceful SIGTERM after confirmation. Stopping one PID can still affect every service owned by that process.
