Not on npm yet. To use the command above, the maintainer must first publish portlane-tui. Until then, clone or download the source and run these local commands.

Designed to stay out of your system's way.

Portlane only shows processes it can safely offer to stop under the current user. It never requires root privileges and never silently kills anything.

Before a stop, Portlane checks process and socket identity again, and sends a graceful SIGTERM after confirmation. Stopping one PID can still affect every service owned by that process.
